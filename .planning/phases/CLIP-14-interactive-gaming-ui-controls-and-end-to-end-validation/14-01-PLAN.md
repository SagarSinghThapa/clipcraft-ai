<objective>
Implement backend data model extensions, candidate update REST endpoint support, export quality overrides, and layout/caption settings inheritance for per-clip customization.

Purpose: Enable the web UI to persist user-selected layout modes, gameplay composition modes (FIT_WITH_BLUR, CROP_FILL, AUTO), streamer height split ratios (25%-50%), stream chat overlay exclusions, caption style presets (GAMING_KARAOKE, CLEAN, MINIMAL), caption placement overrides, and resolution presets (1080p, 1440p, 4K) on individual candidate highlights, ensuring subsequent renders respect these settings without invalidating upstream caches.
Output: Extended candidate models, updated PATCH API route, reframing/caption service fallback inheritance, and backend unit tests.
</objective>
