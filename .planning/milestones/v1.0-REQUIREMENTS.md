## Shipped Requirements

### Media Ingestion (INGEST)
- [x] **INGEST-01**: User can ingest local video files in common formats (MP4, MOV, MKV, WebM) with format and stream metadata validation
- [x] **INGEST-02**: User can ingest videos from authorized YouTube URLs using `yt-dlp` without bypassing DRM, paywalls, or platform security
- [x] **INGEST-03**: Application surfaces clear, human-understandable errors when a media file or URL cannot be processed

### Audio Extraction & Storage (AUDIO)
- [x] **AUDIO-01**: Extract clean 16kHz 16-bit mono PCM WAV audio track from ingested video using FFmpeg
- [x] **AUDIO-02**: Organize ingested source media and extracted audio inside isolated project folders (`projects/<id>/...`)

### Local Transcription (TRANS)
- [x] **TRANS-01**: Transcribe extracted audio locally using `faster-whisper` (or standard Whisper fallback) without cloud API calls
- [x] **TRANS-02**: Output transcript with both segment-level timestamps and individual word-level timestamps
- [x] **TRANS-03**: Persist transcription artifacts to disk (`transcript.json`) to prevent redundant re-transcription on resumed runs
- [x] **TRANS-04**: Support configurable Whisper model sizes (e.g. tiny, base, small)

### AI Highlight Detection (AI)
- [x] **AI-01**: Segment transcript into coherent semantic and syntactic chunks preserving sentence boundaries
- [x] **AI-02**: Implement a local LLM provider abstraction defaulting to Ollama (`/api/generate` or `/api/chat`)
- [x] **AI-03**: Extract candidate clips returning structured JSON: start timestamp, end timestamp, title, rationale, hook assessment, and standalone context
- [x] **AI-04**: Validate and sanitize LLM outputs with deterministic fallback parser handling markdown codeblocks or syntax anomalies

### Explainable Scoring (SCORE)
- [x] **SCORE-01**: Calculate an explainable multi-factor quality score (0–100) combining hook strength, density, clarity, and pacing
- [x] **SCORE-02**: Provide human-readable score breakdown explanation for each candidate clip

### Precision Video Cutting (CLIP)
- [x] **CLIP-01**: Cut source video at exact candidate start and end timestamps using FFmpeg with keyframe accuracy
- [x] **CLIP-02**: Avoid audio drift and black frames at clip boundaries through frame-accurate re-encoding
- [x] **CLIP-03**: Produce standard MP4 clip files with compatible audio/video codecs

### 9:16 Vertical Reframing (REFRAME)
- [x] **REFRAME-01**: Crop and scale video to 9:16 vertical aspect ratio (1080x1920)
- [x] **REFRAME-02**: Detect speaker face/head bounding box using OpenCV to determine horizontal crop focus
- [x] **REFRAME-03**: Smooth crop motion across frames using Exponential Moving Average (EMA) to prevent jitter
- [x] **REFRAME-04**: Fall back safely to centered 9:16 crop when no face is reliably detected

### Synchronized Captions (CAPTION)
- [x] **CAPTION-01**: Generate synchronized vertical video captions chunked into short readable phrases (1-4 words) using word timestamps
- [x] **CAPTION-02**: Style captions with large high-contrast readable typography, outline/shadow, and safe margin positioning
- [x] **CAPTION-03**: Burn captions into exported MP4 using FFmpeg filtergraph
- [x] **CAPTION-04**: Export standard `.srt` subtitle file alongside rendered MP4

### Local Web Interface (UI)
- [x] **UI-01**: Import screen accepting local file paths or YouTube URLs with configurable settings (duration, model, clip count)
- [x] **UI-02**: Processing screen displaying discrete real-time pipeline stage progress (Importing, Transcribing, Analyzing, Reframing, Rendering)
- [x] **UI-03**: Results screen displaying candidate cards with video player, score badges, rationale, duration, and export triggers
- [x] **UI-04**: Basic clip editing controls allowing user to adjust start/end timestamps, rename title, and edit caption text

### System, Hardware & Windows Integration (SYS)
- [x] **SYS-01**: Automatic hardware detection for CPU vs NVIDIA CUDA acceleration
- [x] **SYS-02**: Robust error handling logging root causes for missing FFmpeg, unavailable Ollama, or corrupted media
- [x] **SYS-03**: Windows-compatible startup mechanism (`start.ps1` / `start.bat`) and environment templates (`.env.example`)
- [x] **SYS-04**: Automated test suite verifying pipeline units and end-to-end integration with synthetic media
