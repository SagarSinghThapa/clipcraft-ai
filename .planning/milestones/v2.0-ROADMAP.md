# Milestone v2.0: Gaming & Streamer Vertical Reframing Engine

**Status:** ✅ SHIPPED 2026-11-20  
**Phases:** 10–14  
**Total Plans:** 12 plans across 5 phases  

## Overview

Transforms horizontal gaming and streamer content (e.g. GTA VI, action streams, reaction videos) into professional stacked vertical 9:16 short-form compositions (Top: Streamer Facecam / Bottom: Gameplay) with persistent webcam detection, content-aware gameplay cropping, aspect-preserving `FIT_WITH_BLUR` composition, animated word-level karaoke subtitles, multimodal reaction scoring (audio surges, speech corroboration, facecam/gameplay motion differencing, causal narrative expansion), and interactive web review controls—completely locally without paid external APIs.

## Phases

### Phase 10: Streamer Facecam Detection & Spatial Clustering
**Goal**: Locate the streamer's persistent webcam embedded within 16:9 widescreen gameplay using low-cost spatial clustering across sampled frames.  
**Depends on**: Phases 1–9 (v1.0 foundation)  
**Plans**: 2 plans  
- [x] 10-01: Facecam data models and FacecamService spatial clustering logic
- [x] 10-02: Facecam API routes, metadata integration, and visual debug frame export

**Details:**
Samples video frames at low frequency (1 frame / 2.5s) without full video decoding. Localizes persistent facecam coordinates `(wx, wy, ww, wh)` using spatial quadrant clustering and temporal persistence filtering, rejecting transient cutscene characters. Expands bounding box by 2.0x width / 2.2x height to preserve shoulders, microphone, and 16:9 proportions. Caches facecam metadata to `checkpoint_facecam.json`.

### Phase 11: Modular Gaming Layout Engine & Dual-Stream Compositing
**Goal**: Implement modular layout strategies with stacked FFmpeg filtergraphs (Top Facecam / Bottom Gameplay) and content-aware gameplay cropping.  
**Depends on**: Phase 10  
**Plans**: 2 plans  
- [x] 11-01: Layout data models, multi-resolution canvas presets, and content-aware gameplay cropping
- [x] 11-02: Dual-stream FFmpeg compositing, layout strategy resolution, and reframing API integration

**Details:**
Dual-stream FFmpeg `vstack` compositing producing standard 9:16 vertical video without stretching or distortion. Supports `GAMING_SPLIT`, `GAMEPLAY_FOCUS`, `STREAMER_FOCUS`, and `AUTO_GAMING`. Features `FIT_WITH_BLUR` aspect-preserving composition with ambient blurred background extensions, stream chat overlay exclusion ($X \le 1700\text{px}$), and multi-resolution vertical export presets (1080x1920 FHD, 1440x2560 2K, 2160x3840 4K).

### Phase 12: Animated Word Karaoke Captions & Safe-Zone Placement
**Goal**: Elevate caption engagement with word-by-word karaoke highlighting and safe-zone positioning that avoids obscuring streamer faces or platform UI.  
**Depends on**: Phase 11  
**Plans**: 2 plans  
- [x] 12-01: Caption placement geometry, word-level timing preservation, and karaoke ASS generator
- [x] 12-02: Gaming split seam auto-placement, reframing integration, and caption REST API updates

**Details:**
Word-level synchronized ASS subtitles with active spoken word gold illumination (`&H0000E6FF&`) and 112% pop bounce (`\fscx112\fscy112`). Safe-zone positioning (`TOP`, `CENTER`, `LOWER_CENTER`, `BOTTOM`) defaulting dynamically to `LOWER_CENTER` on the visual split seam, preventing occlusion of streamer faces, gameplay HUDs, and bottom platform UI overlays.

### Phase 13: Reaction-Aware Audio Energy Peak Scoring
**Goal**: Enhance gaming highlight discovery by combining transcript hooks with audio volume surge detection for shouting, laughter, and high-intensity moments.  
**Depends on**: Phase 12  
**Plans**: 3 plans  
- [x] 13-01: Advanced Dual-Baseline Audio Reaction Engine & Speech Corroboration
- [x] 13-02: Staged Visual Reaction Analysis (Facecam + Gameplay) & Causal Sequence Extractor
- [x] 13-03: Multimodal Score Fusion, Saturation Calibration, NMS Deduplication & Pipeline Integration

**Details:**
Replaces single-signal transcript scoring with a balanced multimodal reaction detection engine:
1. $O(N)$ cumulative-sum dual-baseline audio RMS screening (global + local contrast) with a 40% penalty for loud non-speech events (explosions, music).
2. Staged 2 fps visual differencing across facecam (head/body gestures) and gameplay activity regions.
3. Causal micro-narrative framing expanding reaction peaks into complete 20s–60s story arcs (`Setup` $\to$ `Event` $\to$ `Reaction` $\to$ `Payoff`) snapped cleanly to sentence boundaries.
4. Non-linear anti-saturation score calibration ($80 + 15 \cdot \tanh((\text{raw}-80)/15)$) eliminating score ties and temporal NMS deduplication.

## Milestone Summary

**Key Accomplishments:**
1. **Persistent Webcam Detection:** Developed spatial face clustering across coarse video samples (1 frame / 2.5s) to localize streamer facecams without GPU overhead.
2. **Modular Layout & Composition Engine:** Built stacked dual-stream FFmpeg filtergraphs with `FIT_WITH_BLUR` widescreen preservation, chat overlay exclusion, and multi-resolution vertical export up to 4K.
3. **Animated Karaoke Captions:** Designed ASS subtitles with active word gold highlighting and 112% pop bounce, automatically positioned on the split seam to avoid obscuring streamer faces and UI elements.
4. **Multimodal Reaction Scoring:** Engineered balanced highlight detection integrating dual-baseline audio energy surges, speech corroboration, 2 fps facecam/gameplay visual differencing, causal sequence expansion (20s–60s), and calibrated anti-saturation scoring.
5. **Interactive Review & Non-Destructive Editing:** Added fine-grained clip adjustment controls to the web dashboard and verified non-destructive re-rendering preserving all upstream cache checkpoints.

**Key Decisions:**
- [Phase 10]: Spatial clustering on coarse frame samples (1 frame / 2.5s) with quadrant grouping to isolate streamer facecam from transient cutscene faces; 2.0x width / 2.2x height crop expansion.
- [Phase 11]: Dual-stream `vstack` compositing; `FIT_WITH_BLUR` preserves full 16:9 widescreen gameplay context over ambient blurred background; horizontal clamping to $X \le 1700\text{px}$ excludes stream chat overlays.
- [Phase 12]: ASS word-level karaoke subtitles with gold active highlighting (`&H0000E6FF&`) and seam safe placement (`LOWER_CENTER`).
- [Phase 13]: Multimodal score fusion combining audio RMS surges ($Z \ge 2.0$), speech corroboration, 2 fps facecam/gameplay visual differencing, causal sequence micro-narrative expansion (20s–60s), and non-linear score calibration.
- [Phase 14]: Per-clip override persistence via `PATCH /candidates/{id}` with fallback inheritance in reframing and caption services; non-destructive re-rendering preserves upstream stage caches.
