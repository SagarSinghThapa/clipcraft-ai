## Shipped Requirements

### Streamer Facecam Detection & Extraction (FACE)
- [x] **FACE-01**: Sample video frames at low frequency (1 frame / 2–3 sec) to detect faces and calculate spatial persistence across time
- [x] **FACE-02**: Identify persistent streamer webcam bounding box coordinates `(wx, wy, ww, wh)` based on spatial clustering
- [x] **FACE-03**: Expand facecam bounding box to preserve shoulders, microphone, and headroom, and independently crop/zoom streamer reaction without distortion

### Content-Aware Gameplay Cropping (GAME)
- [x] **GAME-01**: Mask out the detected facecam region to analyze pure gameplay activity
- [x] **GAME-02**: Calculate optimal horizontal gameplay crop window using motion/activity density to preserve key action (crosshair, minimap, chases) with EMA motion smoothing

### Modular Layout Engine & Dual-Stream Compositing (LAYOUT)
- [x] **LAYOUT-01**: Implement `GAMING_SPLIT` layout stacking streamer facecam on top and gameplay on the bottom via FFmpeg `vstack`
- [x] **LAYOUT-02**: Implement `GAMEPLAY_FOCUS` layout prioritizing gameplay with smart crop or blurred background extension
- [x] **LAYOUT-03**: Implement `STREAMER_FOCUS` layout dedicating canvas to reaction-heavy moments
- [x] **LAYOUT-04**: Implement `AUTO_GAMING` strategy selector automatically choosing between `GAMING_SPLIT` and `GAMEPLAY_FOCUS` based on facecam presence

### Animated Captions & Safe Placement (CAPTION)
- [x] **CAPTION-01**: Support configurable vertical caption placement: `TOP`, `CENTER`, `LOWER_CENTER`, and `BOTTOM`
- [x] **CAPTION-02**: Automatically place captions at visual seam (`LOWER_CENTER`) during `GAMING_SPLIT` to prevent occluding streamer face or bottom platform UI
- [x] **CAPTION-03**: Render animated word-by-word karaoke highlighting in ASS subtitles (illuminating active spoken word in gold/yellow)

### Reaction-Aware Highlight Scoring (SCORE)
- [x] **SCORE-01**: Extract RMS audio energy across sliding windows to detect volume surges (shouting, laughter, screams, loud reactions)
- [x] **SCORE-02**: Compute a composite gaming highlight score combining transcript hook/novelty score with audio reaction peak score

### Multi-Resolution Vertical Export (EXPORT)
- [x] **EXPORT-01**: Support vertical canvas resolution presets: Full HD (1080x1920), 1440p (1440x2560), and 4K (2160x3840)

### Web Dashboard & User Controls (UI)
- [x] **UI-01**: Add Layout Mode selector (`AUTO`, `GAMING_SPLIT`, `GAMEPLAY_FOCUS`, `STREAMER_FOCUS`, `STANDARD_FACE_TRACK`, `CENTER_CROP`) to the candidate review panel
- [x] **UI-02**: Provide interactive adjustment sliders for Streamer height ratio (25%–50%), Gameplay height ratio, gameplay composition (FIT_WITH_BLUR, CROP_FILL, AUTO), chat overlay exclusion, export quality resolution presets (1080p, 1440p, 4K), and caption position override
