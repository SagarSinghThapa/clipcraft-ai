# Milestone v1.0: AI Video Clipper MVP

**Status:** ✅ SHIPPED 2026-11-19  
**Phases:** 1–9  
**Total Plans:** 13 plans across 9 phases  

## Overview

A local-first, free, and open-source AI video clipping application that transforms long-form videos (local video files or authorized YouTube URLs) into high-impact 9:16 vertical short-form clips. It executes an automated pipeline spanning audio extraction, local transcription with timestamps, transcript segmentation, AI highlight detection, candidate scoring, speaker-aware vertical reframing, and burned-in synchronized captions, previewable and exportable via a modern web interface without requiring paid AI APIs.

## Milestone Summary

**Key Accomplishments:**
1. Built a complete, zero-cost, local-first video clipping pipeline from ingestion to 9:16 MP4 export.
2. Integrated `faster-whisper` on CTranslate2 with CPU int8 quantization and automatic CUDA acceleration.
3. Implemented a resilient 4-tier fallback JSON parser for local Ollama (`llama3.2:3b`) highlight extraction.
4. Developed mathematical 9:16 crop calculation with OpenCV Haar cascade face detection and EMA trajectory smoothing.
5. Engineered high-contrast vertical caption burning using FFmpeg ASS/SRT filtergraphs with safe-margin placement.
6. Delivered an intuitive React + Vite + Tailwind dashboard with real-time stage monitoring and lightweight clip editing.
7. Verified with real 35-minute YouTube media (`https://youtu.be/kR8bhkVAgBY`) with zero errors.

**Key Decisions:**
- Decision: Use Python + FastAPI for backend (Rationale: native ML/AI ecosystem and async throughput).
- Decision: Use React + Vite + Tailwind for frontend (Rationale: fast development, modern UI, smooth video controls).
- Decision: Direct FFmpeg subprocess invocation over MoviePy (Rationale: memory stability and filtergraph performance).
- Decision: Local Ollama provider with structured prompt and deterministic regex fallbacks (Rationale: zero cloud API cost and reliability).
- Decision: Discrete pipeline stage caching to disk (Rationale: avoids re-running expensive downloads or transcription).

**Technical Debt Incurred:**
- Analysis window iteration can be long on CPU for 30+ minute videos if all windows are queried; candidate thresholding added to mitigate.
- Basic face tracking uses Haar cascades; future iterations can support active speaker audio-visual diarization.
